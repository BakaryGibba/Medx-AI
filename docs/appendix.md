## Confidentiality Boundary

This repository omits:

- application source code and infrastructure configuration;
- raw dataset images, labels, slide identifiers, and train/test artifacts;
- trained model weights and serialized pipelines;
- credentials, API keys, endpoints, and storage details;
- patient records and identifiable clinical information;
- the complete final report, signatures, student identifiers, and internal appendices.

## Evidence Source

Technical claims and evaluation figures were summarized from the team's January 2026 final-year project report and the implemented interface screenshots. Results are described as **reported** to distinguish academic evidence from independently verified clinical claims.
